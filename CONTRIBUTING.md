# Contribuindo

## Convenção de notação matemática

A interface deve usar a notação matemática em português, enquanto o motor pode utilizar aliases internos.

- seno: **sen** (internamente `sin`)
- cosseno: **cos** (internamente `cos`)
- tangente: **tan** (internamente `tan`)
- arco-seno: **arcsen** (internamente `asin`)
- arco-cosseno: **arccos** (internamente `acos`)
- arco-tangente: **arctg** (internamente `atan`)
- raiz quadrada: **√** (internamente `sqrt`)
- multiplicação: **×** (internamente `*`)
- divisão: **÷** (internamente `/`)
- expoentes comuns: **²**, **³** etc.
- constantes: **π**, **τ**, **φ**, **e**.

A regra é: **sintaxe interna para o parser; notação matemática para a interface**.
